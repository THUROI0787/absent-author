# Research notes

Raw notes from the research behind the evidence list, compiled in October 2026. They are kept so that anyone can trace where an evidence item came from.

| File | Contents |
|---|---|
| `A_english_social.md` | English-language blogs, Hacker News, venue blogs and news coverage |
| `B_chinese_social.md` | Chinese-language posts and articles (Xiaohongshu, Zhihu, WeChat, Weibo) |
| `C_papers.md` | Research papers and reports |
| `D_github_skills.md` | Writing, reviewing and detection skills on GitHub |
| `E_pipeline_fingerprints.md` | Templates and defaults of open-source auto-research pipelines |

Please read them with these limits in mind:

- Everything quoted here was public when we read it. Quotes are given to show what reviewers and researchers were noticing, not to judge the people who wrote them or any specific paper.
- Quotes were collected with web tools and some are second-hand; each row carries a verification mark. The curated, checked version of every source is [`../SOURCES.md`](../SOURCES.md), and the rest of the repository cites only that file.
- Pipeline fingerprints describe what a pipeline's templates and defaults produce. They are not claims that any particular paper was produced by that pipeline.

If you are quoted here and would like a quote removed or corrected, please open an issue.
