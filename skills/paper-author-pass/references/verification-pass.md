# Pass 3 — Verification

The single most damaging and most common evidence of an absent author is an unverified artifact. ICLR 2026 desk-rejected every paper with a confirmed hallucinated reference; arXiv now bans for a year on incontrovertible unchecked LLM output. Do all of the following; log what you checked.

## 3.1 References (P03, P04)
- For **every** bib entry: confirm the paper exists (title + first author + year + venue) via DOI/DBLP/Semantic Scholar/arXiv, or with `refchecker` (github.com/markrussinovich/refchecker) if installed. Flag: nonexistent, wrong authors (author overlap < 60%), wrong year/venue, DOI pointing elsewhere, merged entries, placeholder authors ("Doe"), X'd arXiv IDs.
- For citations in abstract/intro/related work: open the cited paper (abstract at least) and confirm it supports the sentence. Classic methods should cite the primary source.
- Never write or "fix" BibTeX from memory. Unverifiable → `[AUTHOR TO VERIFY]`.
- Output as `KEEP / FIX / REPLACE / REMOVE` per entry (`[ARIS]` citation-audit convention).

## 3.2 Numbers (R09, R17)
First look next to the paper source for results, logs and code (`run_*/`, `final_info.json`, `notes.txt`, wandb/CSV exports, training scripts); use them read-only.
- List every number in abstract, intro, contributions, discussion, conclusion, captions. Trace each to a table/figure and, if available, to a results file/log.
- Recompute every relative improvement ("+16%": is it (78.0−73.1)/73.1 = 6.7%?), every "average over seeds", every "best".
- Check the same quantity is identical everywhere (agents re-run experiments and forget to update prose).
- Check denominators and dataset/split counts are consistent across sections ("five datasets" vs. four in Table 2).
- **Comparator check:** for every "x% better than Y", confirm Y is the stated comparator. Agents often report a run-vs-previous-run delta as "vs. baseline".
- Check that bold "best" marks the actual best value.
- In audit mode, report the logged value next to the paper's value; correct a number only in revise mode with the author's confirmation.

## 3.3 Plan vs. execution (R07, R08, R10)
- Every analysis/metric/figure mentioned in text exists in the paper (no "reliability diagrams show…" without the diagram).
- Every technique named in title, abstract, section headings is actually run in the experiments.
- Data provenance stated: synthetic? subsampled? generated by which process? overlap between train and test checked? Was any metric changed from the one originally specified, and is that explained?
- Model selection: chosen on validation, not test.
- **Hidden runs:** every configuration shown in any figure appears in the text and tables, and every run in the logs is either reported or its omission is explained.
- **Method section vs. code:** interpolation, loss, sampling equations, seeds (P14).

## 3.4 Residue sweep (P01, P02, P05, P06, P07)
Search the final PDF text **and** the LaTeX source (comments included — arXiv publishes them):
- chatbot/tool residue: "as an AI", "Certainly", "I hope this helps", "regenerate", `oaicite`, `contentReference`, `utm_source=chatgpt`, `turn0search`
- placeholders: `TODO`, `TBD`, `XXX`, `[INSERT`, `??`, `(?)`, "illustrative", "placeholder", lorem ipsum, `PLEASE FILL IN`, `EXAMPLE FIGURE`, `REPLACE AND ADD YOUR OWN` (template comments the lint does not yet catch)
- pipeline watermarks/templates: "generated by", "Research Report:", LLM names in the author block, inline "(arXiv 2308.11483v1)". A watermark or AI author block is removed only together with a human-confirmed disclosure (never in audit or pipeline runs). Semantic-Scholar-style bib keys are not residue.
- source comments: `%` paragraph plans, `<!-- DATA_NEEDED -->`, `% [VERIFY]` → delete before arXiv upload (or use arxiv-latex-cleaner)
- code identifiers in prose/legends: `run_3`, `config_A2`, `v3_final`, raw snake_case dataset names → replace with readable names

The lint (`python scripts/slop_lint.py --source …` from the skill folder, or the script's absolute path) finds candidates for most of these.

## 3.5 Figures (P08)
- Text inside figures readable and spelled correctly; axes/legends meaningful (no run IDs).
- Captions describe what the figure actually shows (trend direction!).
- AI-generated method diagrams must match the method as described; remove decorative ones.
- No duplicate figures (main vs. appendix; per-seed vs. aggregate).

## 3.6 Disclosure (P10)
Check the target venue's current AI-use policy (ICLR 2027: mandatory statement). Draft the statement from `ai-contribution-statement.md` with confirmed facts only.
